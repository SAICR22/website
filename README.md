# Itami Food Consulting

Site institucional da Itami Food Consulting, consultoria B2B para a indústria de alimentos.

## Tecnologias

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- CSS responsivo e animações nativas
- Vercel

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

O site estará disponível em `http://localhost:3000`.

## Build

```bash
pnpm build
pnpm start
```

## Configuração opcional

Copie `.env.example` para `.env.local` e informe `NEXT_PUBLIC_WHATSAPP_URL` para exibir o acesso ao WhatsApp.

## Domínio

O domínio oficial é `itamifood.com.br`. A conexão ao domínio será feita depois da configuração do Google Workspace, preservando os registros de e-mail.
